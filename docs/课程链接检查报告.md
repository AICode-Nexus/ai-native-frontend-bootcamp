## 🔍 验证方法说明

### 基础验证
```bash
curl -o /dev/null -s -w "%{http_code}" -L --max-time 10 "URL"
```

### 反爬验证（对 403/429 使用浏览器 UA 重试）
```bash
curl -o /dev/null -s -w "%{http_code}" -L --max-time 15 \
  -H "User-Agent: Mozilla/5.0 (Macintosh; Intel Mac OS X 14_0) AppleWebKit/537.36..." \
  "URL"
```

### 状态码含义
- **200**: 正常
- **301/302**: 重定向（已通过 `-L` 跟随）
- **403/429**: 反爬或限流（内容本身未失效）
- **404**: 真正失效（需修复）

## 📋 建议的链接维护流程

### 高频变动链接（建议每月检查）
- Figma 官方博客（路径经常变）
- GitHub 项目（owner 可能迁移）
- 技术博客（可能被删除）

### 稳定链接（建议每季度检查）
- 主流技术的官方文档（Tailwind、Next.js、React 等）
- npm/PyPI 包页面

### 快速检查脚本

保存以下脚本为 `scripts/check-links.sh`，定期运行：

```bash
#!/bin/bash
# 提取所有链接
grep -rohE 'https?://[a-zA-Z0-9./?=&_#%:+-]+' 第*课*/final-content.md \
  | grep -v 'example.com\|localhost' \
  | sort -u > /tmp/links.txt

# 批量检查
while IFS= read -r url; do
  code=$(curl -o /dev/null -s -w "%{http_code}" -L --max-time 10 "$url")
  [[ "$code" != "200" ]] && echo "❌ $code $url"
done < /tmp/links.txt
```
