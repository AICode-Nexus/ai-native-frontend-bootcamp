## ⚠️ 需要持续关注的版本

以下技术演进速度快，建议每月复核一次：

### 高速演进（每月复核）

1. **shadcn/ui CLI**：`npx shadcn@latest` 命令本身会自动用最新版，但 Registry v2 等新特性需要关注
2. **Vercel AI SDK**：v6 → v7 的升级可能带来 API 变化
3. **Cursor / Windsurf**：新功能发布频繁
4. **Claude 模型**：Anthropic 会持续发布新版本

### 稳定演进（每季度复核）

1. **Tailwind CSS v4**：次版本号（v4.2、v4.3 等）
2. **Next.js 15**：App Router 新特性
3. **React 19**：Server Components、Actions API
4. **Radix UI**：新原语发布
5. **Turborepo**：构建优化、Remote Caching 改进

### 低频演进（每半年复核）

1. **Biome**：2.0 → 3.0 的大版本升级
2. **pnpm**：workspace 协议改动
3. **TypeScript**：5.5 → 5.6 → 5.7 等

## 📝 版本更新决策树

当发现技术有新版本时，按以下流程决策是否更新课程：

```
发现新版本
    ↓
是否引入破坏性变更？
    ├─ 是 → 评估影响面：
    │       ├─ 只影响代码示例 → 课程内更新（需要测试代码示例）
    │       └─ 影响核心概念 → 重写相关章节
    └─ 否 → 评估是否有新特性值得讲：
            ├─ 有 → 在"新特性"段落补充
            └─ 无 → 只更新版本号引用
```
